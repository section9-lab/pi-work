# PiWork 0.1.44

## Mermaid 图表

- macOS 14 及以上，会话里的 ```mermaid 围栏由原生 MermaidKit 渲染成图，不再显示源码。
- 覆盖 flowchart、sequence、state、class、ER 等 30 种类型的核心语法；subgraph、`<br/>` 多行标签、中文标签均按原样排版。
- 图按正文列宽缩放；点击图表打开可滚动的大图，Esc 或 Done 关闭。
- 自动回退：语法错误、不支持的方言、超过 50k 字符的源码仍显示为代码块。
- macOS 13 Ventura 行为不变：围栏继续以代码块显示，渲染器按系统版本门控，不执行任何图表代码。
- 依赖锁定到 `section9-lab/MermaidKit` 的 pi-work fork（macOS 13 平台下限、无 Linux 依赖图）。

## Mermaid diagrams

- On macOS 14 and later, ```mermaid fences in a session render natively with MermaidKit instead of showing source.
- Covers the core syntax of 30 diagram types, including flowchart, sequence, state, class and ER; subgraphs, `<br/>` multi-line labels and CJK labels lay out as written.
- Diagrams scale to the transcript column; click one to open a scrollable full-size view, dismissed with Esc or Done.
- Automatic fallback: syntax errors, unsupported dialects and sources over 50k characters keep rendering as code blocks.
- macOS 13 Ventura is unchanged: fences stay code blocks. The renderer is gated by OS version and runs no diagram code there.
- The dependency is pinned to the `section9-lab/MermaidKit` pi-work fork (macOS 13 platform floor, no Linux dependency graph).

## Code blocks

- Fixed over-wide single-line code blocks whose selection layer escaped the card, painted over the transcript gutter and ran to the window edge.
