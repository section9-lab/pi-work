# PiWork 0.1.33

## 汇总此前未发布的改动

本版在 v0.1.32 的历史消息加载修复基础上，包含此前留在工作区、尚未提交的 MCP 市场和输入框显示调整。

## MCP 市场

- 设置 → MCP 新增可搜索的内置市场，提供 Context7、Playwright、DeepWiki、Exa、Sentry、Linear、Notion、Supabase、Stripe、Vercel、Cloudflare Docs、Microsoft Learn 和 Hugging Face 共 13 个连接预设及设置文档入口。
- 浏览市场不会安装、执行本地命令或授予权限。远端预设可由用户点击添加；需要登录且支持 OAuth 的服务可进入已有登录流程。
- Playwright 先打开预填命令的编辑器，提示其将通过 npx 下载并运行本地进程，需要安装 Node.js 并检查命令后继续。
- 按服务地址或命令识别已添加项；名称冲突自动生成后缀，避免覆盖自定义连接。新增连接不自动获得 Chat 或只读工具权限。
- 改善已添加服务与市场的分区、错误提示、本地命令警告和原生 SF Symbols 图标，补齐六语言文案与回归检查。

## 会话输入框

- 切换会话时保留输入框与项目、模型等控件的显示，不再用加载遮罩覆盖整个输入区；切换完成前仍禁用交互，防止发送到上一条会话。
- 保留前版的独立会话草稿、提问导航和历史分页修复。

## Previously unshipped changes included

This release includes the previously uncommitted MCP market and composer presentation changes on top of v0.1.32's history-loading fixes.

## MCP market

- Settings → MCP now includes a searchable bundled catalog of 13 connection recipes: Context7, Playwright, DeepWiki, Exa, Sentry, Linear, Notion, Supabase, Stripe, Vercel, Cloudflare Docs, Microsoft Learn and Hugging Face, with links to setup documentation.
- Browsing does not install anything, execute local commands or grant permissions. Users can explicitly add remote recipes; services requiring sign-in can enter the existing OAuth flow when supported.
- Playwright opens a prefilled editor with a warning to review its npx command and install Node.js before downloading and running local code.
- Recognizes existing endpoints/commands, suffixes conflicting names rather than overwriting custom connections, and never automatically grants Chat or read-only tool access.
- Refines installed-server/catalog sections, errors, local-command warnings and native SF Symbols, with all six localizations and regression checks.

## Session composer

- Keeps the input surface, project and model controls visible during session transitions instead of covering the composer with a loading overlay. Interaction remains disabled until the selected conversation is ready.
- Retains independent session drafts, prompt navigation and the previous history-pagination fixes.
