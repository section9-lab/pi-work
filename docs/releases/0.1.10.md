pi-coding-agent can now be updated from Settings → General without replacing the App.

- Independent runtime packages for Apple Silicon and Intel, checked against the App version, macOS version, CPU architecture and adapter protocol.
- Download size, SHA-256, complete file inventory and executable signatures are verified before an isolated startup and SDK health check.
- Updates take effect on the next launch. Startup failures and runtime crashes restore the previous working runtime or the bundled version. Pending updates can be cancelled and active updates can be rolled back in Settings.
- The runtime update channel is separate from App releases. This release bundles pi-coding-agent 0.84.1 and runtime 1.0.0.

现在可在「设置 → 通用」中独立更新 pi-coding-agent，无需替换整个 App。更新会先完成兼容检查、完整性校验和隔离启动测试，下次启动生效；失败时自动恢复上一可用版本或内置版本，也可手动取消待生效更新或回退。
