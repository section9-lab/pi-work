# PiWork 0.1.36

## 官方 MCP Registry 市场

- MCP 市场现在实时读取官方 MCP Registry，不再局限于内置的固定服务列表；支持远程搜索、分页加载，以及远程与本地服务筛选。
- 服务卡片显示 Registry 提供的发布者图标，并在不可用时依次使用仓库头像、站点图标或稳定的文字占位图标。
- HTTP、npm/npx 与 PyPI/uvx 配置会先进入编辑器供用户确认；所需环境变量、请求头、参数占位符与运行时注意事项都会明确展示。
- 增加安全限制，拒绝本地地址、凭据 URL、私有 IP 图标和不受支持的传输方式；浏览市场不会自动运行服务或授予权限。
- 增加分页去重、短期内存缓存和首屏离线缓存；搜索或分页失败不会错误显示无关的缓存结果，也不会影响已经添加的服务。

## 工具与界面细节

- Computer Use 设置入口改用苹果官方 `rectangle.and.hand.point.up.left` 图标，不再因缺少映射而显示叉号。
- 编辑工具改用 `highlighter` 图标，更容易与文件写入操作区分。
- 折叠的“已完成步骤”标题不再占据整行透明点击区域，展开后的工具详情仍可使用完整内容宽度。
- MCP 市场和已添加服务使用更紧凑的自适应卡片，并完善六种界面语言的 Registry 状态与配置提示。

## Official MCP Registry market

- The MCP market now reads the official MCP Registry live instead of relying on a fixed bundled list, with remote search, pagination, and remote/local filters.
- Server cards display publisher artwork from registry metadata, falling back to repository avatars, site icons, or stable text monograms.
- HTTP, npm/npx, and PyPI/uvx recipes always open in the editor for review. Required environment variables, headers, argument placeholders, and runtime notes are surfaced before saving.
- Adds safety checks that reject local addresses, credential-bearing URLs, private-IP artwork, and unsupported transports. Browsing never runs a server or grants permissions.
- Adds pagination deduplication, short-lived memory caching, and an offline first-page cache. Failed searches or pagination never substitute unrelated cached results or affect added servers.

## Tool and interface refinements

- Uses Apple’s official `rectangle.and.hand.point.up.left` symbol for Computer Use instead of falling back to an X icon.
- Uses the `highlighter` symbol for edit tools, making them easier to distinguish from file writes.
- Keeps collapsed “Completed steps” headers compact instead of giving them an invisible full-row click target, while expanded details retain the available width.
- Uses denser adaptive cards for the MCP market and added servers, with complete registry and setup messaging across all six interface languages.
