App update checks now recover when GitHub's anonymous API request quota is exhausted or the API is unavailable.

- Fall back to GitHub's public latest-release redirect and verify that an installer exists for this Mac using HEAD requests.
- Validate the repository, release tag and download destination before offering an update.
- Show specific update failure reasons in Settings and the update dialog, with translations for all six supported languages.
- pi-coding-agent remains independently updatable. This release bundles pi-coding-agent 0.84.1 and runtime 1.0.0.

修复「软件更新」因 GitHub 匿名 API 限流而检查失败的问题。API 不可用时，自动通过公开 Release 地址检查新版及当前 Mac 对应的安装包；失败时显示具体原因。pi-coding-agent 仍可在软件内独立更新。
