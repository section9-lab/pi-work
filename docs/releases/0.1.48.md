# PiWork 0.1.48

## 修复

- 修复 0.1.47 中打开会话后助手回复正文不显示的问题：历史消息与已完成回复不会经过流式渲染路径，其文本块没有被交给块级渲染器，导致只剩工具调用和思考可见。现在初始化时直接生成完整块，并在块列表为空时回退到整篇渲染，避免再次出现空白回复。

## 自动检查更新

- 工作时间（本地时间 09:00–19:00，共 10 小时）内每 10 分钟检查一次；工作时间之外保持每小时一次。
- 09:00 与 19:00 两个边界会即时切换节奏，不会多等一个周期。
- 改动系统时区、系统时间，或从睡眠唤醒后，都会按当前时间重新计算下一次检查。
- Sparkle 在 Release 构建中把检查间隔下限固定为 1 小时，因此高频检查由应用自身调度，Sparkle 原有的自动检查保持不变。
- 关闭"自动检查更新"后不会再有任何后台检查。

## Fixes

- Fixed the missing assistant body introduced in 0.1.47: messages loaded from a session or completed before the row appeared never pass through the streaming renderer, so their text block was never handed to the block renderer and only tool calls and thinking stayed visible. Stored text is now seeded as a complete block, and an empty block list falls back to whole-document rendering.

## Automatic update checks

- Every 10 minutes during local working hours (09:00–19:00, ten hours), hourly outside them.
- The 09:00 and 19:00 boundaries switch the cadence immediately instead of waiting a full interval.
- Changing the system time zone or clock, or waking from sleep, recomputes the next check from the current time.
- Sparkle clamps its check interval to one hour in release builds, so the frequent checks are scheduled by the app while Sparkle's own automatic checks stay in place.
- Turning off automatic checks stops all background checks.
