# PiWork 0.1.46

## 输入框

- 恢复输入框左下角的加号：点击后可从系统选择器添加图片附件，支持多选。
- 图片沿用现有处理链路，包含格式校验、数量与大小限制、缩略图预览和发送前移除。
- 当前 Agent 协议只接受图片作为附件，普通文件暂不支持上传。

## 后台会话

- 后台运行的会话完成或失败后，如果当前没有显示该会话，左侧列表会在行尾显示未读圆点。
- 点击该会话或切换到它后，圆点立即消失。
- Chat 与 Work 列表都支持；运行中的会话仍显示旋转状态。
- 删除会话或项目时会同步清理未读状态。

## Composer

- Restored the plus button at the bottom-left of the composer. It opens the system picker for one or more image attachments.
- Images reuse the existing processing pipeline, including format checks, count and size limits, thumbnails and removal before sending.
- The Agent protocol currently accepts images only; arbitrary file uploads are not supported yet.

## Background sessions

- When a background session finishes or fails while its conversation is not on screen, its sidebar row now shows an unread dot.
- Opening or switching to that session clears the dot immediately.
- This works in both the Chat and Work lists, while running sessions keep showing the spinner.
- Deleting a session or project also clears its unread state.
