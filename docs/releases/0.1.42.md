# PiWork 0.1.42

## 变更查看与上下文压缩

- 将项目 Diff 改为纵向变更流，按文件展示变更内容、状态和增删行数，并保留文件筛选。
- Diff 与对话并排显示，不再遮挡输入框；可拖动分隔线调整宽度，调整窗口宽度时优先改变 Diff 区域。
- 调整 Diff 关闭按钮的位置，并改进上下文压缩按钮的样式。

### 已知性能限制

复杂 Markdown 的长会话在直播更新或滚动时仍可能卡顿或落后。压力测试尚未通过性能验收；高负载会影响结果，排版性能优化仍在调查中。

## Changes review and context compaction

- Shows project diffs as a vertical feed with file status, additions and deletions, while retaining file filtering.
- Keeps the diff alongside the conversation without covering the composer. Drag the divider to resize it; resizing the window prioritizes the diff pane while it is open.
- Moves the diff close button and refines the context compaction button.

### Known performance limitation

Long conversations containing complex Markdown may still stutter or fall behind during streaming or scrolling. Stress tests have not passed performance acceptance; system load affects results and layout-performance work remains under investigation.
