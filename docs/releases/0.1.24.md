# PiWork 0.1.24

## 侧栏更新入口

- 后台自动发现新版本后，在账户行右侧显示上箭头，点击即可开始更新。
- 下载与解压时显示紧凑的圆形进度，已知下载大小时按百分比绘制圆环。
- 安装完成后自动重启；保留运行中任务的重启保护，避免中断工作。
- 更新入口与账户按钮独立，点击更新不会打开账户菜单。

## 右上角项目菜单

- 扩大按钮的完整矩形点击区域，不再只依赖细小图标的命中范围。
- 修正标题栏拖拽层的坐标转换，避免拖拽层拦截项目菜单点击。

## Sidebar updates

- Show an up-arrow beside the account row when an automatic check finds a new version.
- Clicking the arrow starts the update; downloading and extraction use compact circular progress, with a percentage ring when the content length is known.
- Automatically relaunch after installation while preserving active-task restart protection.
- Keep update and account interactions separate.

## Project menu hit testing

- Expand the top-right menu's rectangular click target.
- Correct titlebar drag-region coordinate conversion so window dragging does not steal menu clicks.
