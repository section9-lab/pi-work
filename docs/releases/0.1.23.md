# PiWork 0.1.23

## 更紧凑的工具展示

- 工具输入和输出移除重复标题，缩小卡片间距，短内容按实际行数收紧高度。
- Bash 输入直接显示命令；读取输入显示路径与读取范围。
- 其他工具参数改用易读的键值展示，减少 JSON 外层括号和转义噪声。
- 保留输入和输出的复制入口。

## 单栏代码差异

- 编辑预览从左右并排改为单栏逐行 diff，改善窄窗口阅读体验。
- 文件标题显示新增、删除行数，支持复制修改后的内容。
- 删除行使用红色、新增行使用绿色，未变内容保留为上下文。
- 短 diff 不再占用大块空白，长 diff 使用统一滚动区域。
- 工具只提供文本片段时不显示未经确认的文件绝对行号。

## Compact tool details

- Remove redundant input/output headings and reduce card spacing and short-content height.
- Show Bash commands directly and read requests as a path with optional range parameters.
- Present other tool arguments as readable key/value text while retaining copy controls.

## Unified edit previews

- Replace side-by-side text boxes with a single line-by-line diff.
- Show file names, added/deleted line counts, and a copy action for the updated snippet.
- Highlight removed and added lines while preserving unchanged context.
- Use content-sized previews with shared scrolling for longer changes.
