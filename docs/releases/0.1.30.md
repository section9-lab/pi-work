# PiWork 0.1.30

## 消息导航

- 重新设计右侧提问导航：每条用户消息默认显示为一个短点，当前阅读位置使用强调色标记。
- 鼠标进入导航区域后，短点依次展开为横杠；长会话可在区域内上下滚动，不再把标记挤在一起。
- 悬浮横杠即可预览对应提示词，点击后跳转并短暂高亮原消息。离开区域后自动收起，不再显示独立的目录按钮和列表面板。
- 导航覆盖所有已加载的用户消息；选择近期渲染窗口之外的提问时，会先展开相应历史内容再跳转。
- 保留提示词原文与段落，并支持键盘焦点、减少动态效果、高对比度及六种语言的阅读位置提示。

## 草稿与会话操作

- 每个 Session 独立保留未发送的文字、已选命令和截图；切换会话、项目或前往技能等页面后，返回时恢复原草稿。本版保留范围为当前应用运行期间，不包含退出后恢复。
- 截图即使在切换后才处理完成，也只会回到原会话；发送确认不会清掉等待期间新编辑的内容。发送失败保留草稿，删除会话时清理对应草稿。
- 修复右键菜单蓝色轮廓比会话行选中背景更宽的问题。
- 修复使用 ACP Session ID 导出 HTML 时被误判为文件路径不匹配的问题，兼容已打开与未打开的会话；导出后明确使用系统默认浏览器打开。
- 右上角项目菜单在点击标题栏、侧边栏、其他窗口或切换到其他应用后自动关闭；Esc 和再次点击按钮同样可以关闭，选择“变更”后也会收起。

## 技能卡片

- 图标与技能名称改为并排显示，缩小卡片高度并同步调整加载占位布局。
- 精简卡片底部信息，保留官方标识、安装量和下载操作；分类继续通过顶部筛选呈现。
- 安装量省略多余的小数尾零，改善窄列下的文字与按钮显示。

## Prompt navigation

- Redesigned the prompt rail with one short mark per user message and an accent-colored reading position.
- Hovering over the rail progressively expands the marks into bars. Long conversations scroll within the rail instead of compressing their targets.
- Hover a bar to preview its prompt; click to jump to and briefly highlight the original message. The rail collapses when the pointer leaves, replacing the separate index button and panel.
- All loaded user turns are indexed, including those outside the recent rendering window; selecting an older turn expands the required history before jumping.
- Preserves original prompt text and paragraphs, with keyboard focus, reduced-motion and increased-contrast support, plus reading-position labels in all six languages.

## Drafts and session actions

- Unsent text, selected commands and screenshots are now independent per session and survive session/project switches and visits to other destinations during the current application run. Drafts are not yet restored after quitting.
- Asynchronous image processing stays attached to the original draft. Send acknowledgements preserve edits made while waiting; failed sends keep the draft, and deleting a session removes its draft.
- Aligned the context-menu outline with the session row's selected background.
- Fixed HTML export rejecting ACP session IDs as mismatched filesystem paths, for both open and closed sessions. Reports explicitly open in the system's default web browser.
- The upper-right project menu now dismisses for title-bar/sidebar clicks, other windows, app deactivation and Escape. Selecting Changes also closes the menu.

## Skill cards

- Placed skill icons beside their names for more compact cards and matching loading placeholders.
- Simplified the footer to official status, install count and download controls; categories remain available through the filters.
- Removed redundant decimal zeros from install counts to improve narrow-column layouts.
