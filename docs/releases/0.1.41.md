# PiWork 0.1.41

## 对话与历史

- 隔离直播文本更新和会话列表投影，减少对不相关消息的刷新；历史阅读时保留当前位置，并改进历史窗口切换后的锚点恢复。
- 改进工具调用的分组、展开状态和写入行数展示，以及上下文压缩结果的显示。
- 项目侧边栏默认折叠较长的会话列表，同时保留当前选中的会话；调整设置侧边栏布局。

### 已知性能限制

复杂 Markdown 的长会话在直播更新或滚动时仍可能卡顿或落后。压力测试尚未通过性能验收；高负载会影响结果，排版性能优化仍在调查中。

## Conversations and history

- Isolates streaming text updates from the transcript projection to reduce unrelated row updates, preserves the reading position during streaming, and improves anchor restoration after history-window changes.
- Improves tool-call grouping, expansion state and written-line counts, as well as the presentation of compaction results.
- Collapses long project session lists by default while keeping the selected session visible, and refines the settings sidebar layout.

### Known performance limitation

Long conversations containing complex Markdown may still stutter or fall behind during streaming or scrolling. Stress tests have not passed performance acceptance; system load affects results and layout-performance work remains under investigation.
