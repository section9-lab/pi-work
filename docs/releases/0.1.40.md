# PiWork 0.1.40

## 上下文压缩

- 新增手动压缩入口和 `/compact [instructions]` 命令；压缩过程中可查看状态，并在运行时支持时独立取消。
- 在会话中保留压缩结果、摘要和错误记录；支持查看、复制摘要及在适当时重试，并区分实际费用与估算费用。
- 压缩期间的待发送输入会安全排队；压缩取消或失败时恢复未发送输入，不会静默丢失。
- 会话历史改为读取当前分支的原始记录，压缩后仍可查看原始对话及按需读取工具输出；未知的压缩后 token 数不会被显示为零。

## 长会话与工具展示

- 长会话使用最多 120 条源消息的双向渲染窗口，向上加载历史后可继续向下浏览至最新消息，同时保持视口锚点并避免懒加载高度估算导致反复回跳。
- 历史阅读期间的新流式消息不会推走当前位置；保留提问导航、跳到最新和完整的已加载提问历史。
- Bash 工具详情支持自动换行，输出可切换换行，复制时保留原始文本；上下文用量尚未计算时保持圆环图标。
- 调整浅色窗口背景的蓝色渐变，深色外观保持不变。
- 合并 macOS 系统路径配置并保留现有 PATH 的优先级，帮助图形界面启动的进程发现 Homebrew 和系统命令。

## Context compaction

- Adds manual compaction from the context popover and `/compact [instructions]`. Shows operation status and supports independent cancellation when the runtime provides it.
- Preserves compaction outcomes, summaries, and errors in the transcript. Summaries can be viewed and copied, eligible failures retried, and billed costs distinguished from estimates.
- Safely queues input during compaction and recovers unsent input on cancellation or failure instead of silently discarding it.
- Reads conversation history from the active branch's original entries after compaction, with full tool output available on demand. Unknown post-compaction token counts are not presented as zero.

## Long conversations and tool presentation

- Uses a bidirectional render window of at most 120 source messages. Readers can load earlier history and continue down to the latest message while retaining their viewport anchor, avoiding repeated jumps from lazy height estimates.
- Keeps the reading position stable when streaming messages arrive, while retaining prompt navigation, jump-to-latest, and the full loaded prompt history.
- Wraps Bash tool details, provides a wrapping toggle for output, and copies the original text unchanged. The context indicator remains a ring while usage is being calculated.
- Refines the blue gradient in the light window backdrop without changing the dark appearance.
- Merges the macOS system path configuration while preserving the existing PATH priority, helping GUI-launched processes find Homebrew and system commands.
