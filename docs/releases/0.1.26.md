# PiWork 0.1.26

## 提示词导航

- 对话右侧新增提示词刻度栏，一轮一个刻度，跟随当前轮次高亮。
- 指向刻度即显示该轮的单行预览与图片数量，点击直接跳转。
- 刻度上方的抓手可展开完整索引，不占用正文宽度。

## 对话内错误提示

- 把上游不可用、凭证失效、限流、超时、连接中断、会话仍在运行和内部错误分开呈现，每种都给出原因与下一步操作。
- 「查看详情」可展开原始技术信息；出错的那一轮不会再只显示一句无法操作的报文。
- 不再把内部错误码（如 `invalid_request`）或原始枚举文本直接抛到对话里；无法归类的失败会保留原始信息作为详情。

## 上下文用量

- 输入框下的 Context 面板新增用量构成：系统提示词、工具定义、对话、连接器与 MCP、技能、项目上下文。
- 同时显示已用 / 窗口与预估费用，便于判断是哪一部分挤占了上下文。

## 模型与思考强度

- 模型选择与思考强度合并为一个选择器，选择模型后可直接调整强度。
- 支持快速模式的模型在列表中直接标记；快速模式与 1M 上下文开关增加了标题与说明。

## 其他

- 思考过程支持 Markdown 渲染，不再显示原始标记。
- 设置页统一分组样式，移除多余的 Pi Coding Agent 分区，版本信息只保留版本号。

## Prompt navigation

- New prompt rail in the transcript gutter, one tick per user turn, with the current turn highlighted.
- Pointing at a tick previews that turn on one line with its image count; clicking jumps there.
- The grip above the ticks opens the full index without taking width from the conversation.

## In-conversation errors

- Upstream unreachable, rejected credentials, rate limits, timeouts, lost connections, busy sessions and internal failures are now presented separately, each with a cause and a next step.
- View details reveals the original technical message, so a failed turn is never just an unactionable sentence.
- Internal codes such as `invalid_request` and raw enum dumps no longer reach the conversation; unclassified failures keep their original message in the details.

## Context usage

- The Context popover under the composer now breaks usage down into system prompt, tool definitions, conversation, connectors and MCP, skills, and project context.
- It also shows used versus window and the estimated cost, so it is clear which part is consuming the budget.

## Model and reasoning effort

- Model selection and reasoning effort are merged into one picker; effort is adjustable right after choosing a model.
- Models that support fast mode are marked in the list, and the fast mode and 1M context switches now carry titles and explanations.

## Other

- Thinking content renders as Markdown instead of raw markup.
- Settings pages share one grouping style, the redundant Pi Coding Agent section is gone, and the version row shows only the version.
