# PiWork 0.1.27

## 技能商场图标

- 每张技能卡左上角新增图标：优先显示技能作者在 GitHub 上的真实头像，取不到时退回首字母色块，同一个技能的颜色始终固定。
- 图标与卡片同时渲染，滚动、刷新、切换分类都不会出现空位或跳动；离线时直接显示字母色块。
- 卡片高度相应加高，标题、说明、下载按钮的相对位置保持不变。

## 工具输出细节

- 工具详情与 diff 卡片右上角的复制按钮改为鼠标悬浮时才显示，不再常驻。
- 工具详情的内容与工具图标左边缘对齐，缩进更紧凑。

## Skill catalog icons

- Every skill card now shows an icon in its top-left corner: the author's real GitHub avatar when available, otherwise a stable monogram tile, so the same skill always keeps the same colour.
- Icons render together with the card, so scrolling, refreshing and switching categories never show a gap or cause a jump; offline it simply falls back to the monogram.
- Cards are slightly taller to make room, while the title, summary and download button keep their relative positions.

## Tool output details

- Copy buttons on tool detail and diff cards now appear on hover instead of staying permanently visible.
- Tool detail content aligns with the leading edge of the tool icon, with tighter indentation.
