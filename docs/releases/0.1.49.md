# PiWork 0.1.49

## 新建会话更跟手

- 点击“新建会话”后立即出现新会话行和加载状态，不再停留在旧会话上等待 host 返回。
- 新会话使用客户端生成的 session ID，host 返回后原地替换，输入草稿不会因为 ID 变化而丢失；失败或取消会恢复之前的选中会话。
- Work 项目的新建会话不再先等待会话列表和模型列表；侧边栏刷新改为后台进行，并合并结果，不会覆盖刚创建的草稿。

## 会话启动诊断

- 为 `session.createDraft` 增加完整阶段耗时埋点：host ready、RPC、snapshot、projection、publish、selection。
- Agent Host 输出 `PIWORK_PERF` 阶段日志，可在 Console 的 `AgentHostTiming` 分类下查看 `resourceLoader`、`createAgentSession`、`bindExtensions`、`acpState` 等耗时。
- 首次打开历史会话的现有 `SessionOpen` trace 保持不变。

## Faster new-session feedback

- A new session row and loading state now appear immediately on click, instead of leaving the previous conversation visible during the host round trip.
- The client supplies the session ID, so the provisional record is replaced in place; composer drafts keep their key, and failures or cancellations restore the previous selection.
- Work session creation no longer waits for the project's session list or model catalog. The sidebar refresh runs in the background and merges results without dropping the new draft.

## Session startup diagnostics

- Added full draft startup tracing: host ready, RPC, snapshot, projection, publish, and selection.
- The Agent Host emits `PIWORK_PERF` phase logs, visible under the `AgentHostTiming` Console category, covering resource loader, agent session, extension binding, ACP state, and total host time.
- Existing `SessionOpen` first-open tracing is unchanged.
