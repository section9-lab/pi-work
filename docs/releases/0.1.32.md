# PiWork 0.1.32

## 修复向上滚动无法加载历史消息

- 修复普通鼠标滚轮滚到会话顶部却不加载的问题：原实现依赖连续滚动开始通知，部分无手势阶段的滚轮输入不会产生该通知。现在直接检测会话区域内的滚轮输入，同时保留触控板支持。
- 根据正文与可见区域的真实几何位置判断顶部和底部，不再依赖滚动条是否存在及其显示值。
- 每次历史加载结束或失败后重新启用触发，支持停留在顶部继续上滚、连续加载多页或重试，不必先往下滚一段。
- 顶部增加“加载更早的消息”手动入口和加载状态，六种语言同步提供。
- 加载时暂停自动跟随并恢复原阅读行；初次打开会话的分批渲染不再将正在查看历史的用户拉回底部。
- 验证覆盖真实 ChatView 中的缓存历史展开、两次远端分页、失败后原地重试和阅读锚点，以及普通滚轮、触控板及嵌套滚动区域隔离。

## Fix upward scrolling not loading earlier messages

- Fixed ordinary mouse wheels reaching the transcript top without loading history. The previous implementation depended on live-scroll start notifications that phase-less wheel input may never emit. The transcript now detects wheel input directly while retaining trackpad support.
- Top/bottom detection uses actual document and viewport geometry instead of depending on scrollbar presence or its displayed value.
- History loading rearms after completion or failure, allowing another wheel notch at the same top position to load the next page or retry.
- Added a manual Load earlier messages control and loading feedback at the top, localized in all six languages.
- Pauses auto-follow while loading and restores the previous reading row. Initial batched rendering no longer pulls readers back to the tail while they inspect history.
- Regression coverage exercises cached history, two remote pages, retry after failure and reading anchors in the real ChatView, plus phase-less mouse wheels, trackpads and nested-scroll isolation.
