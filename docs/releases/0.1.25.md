# PiWork 0.1.25

## 执行中追加消息

- 任务执行期间可继续发送消息，发送与停止按钮独立显示。
- 在「设置 → Agent」选择 Follow-up（完成后执行）或 Steer（追加指示），默认 Follow-up。
- 显示待处理消息及图片附件；支持取消全部，并恢复未处理内容到输入框。
- 直接使用 Pi 原生队列，保持同一会话的任务顺序，避免并行启动任务。
- 停止任务时清理未处理消息，避免队列重新启动任务；改进消息投递、取消和会话状态的竞态处理。
- 更新内置 Agent Runtime 至 1.1.3。

Steer 会在下一个可接收指示的节点生效，不会立即中断正在执行的工具。需要立即终止当前任务时，请使用停止按钮。

## Messages during execution

- Send messages while a task is running, with separate send and stop controls.
- Choose Follow-up or Steer in Settings → Agent. Follow-up is the default.
- Inspect pending messages and image attachments, cancel all pending inputs, and restore unprocessed content to the composer.
- Use Pi's native queues without starting parallel runs in the same session.
- Clear pending inputs when stopping, preventing unintended restarts; improve delivery, cancellation and session-state race handling.
- Update the bundled Agent Runtime to 1.1.3.

Steer takes effect at the next available instruction boundary; it does not immediately interrupt a running tool. Use Stop to terminate the current task.
