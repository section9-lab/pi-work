# PiWork 0.1.37

## Pi 1.5 与运行时安全

- 将 Pi AI、Coding Agent 与 TUI 统一升级到 1.5.0，并增加真实 Agent Loop、OAuth 摘要、MCP OAuth、参数校验和 macOS Shell 取消等契约回归测试。
- 只读模式现在使用 Pi 自身的路径解析规则统一处理 `@`、`~`、文件 URL 和 macOS 文件名变体；授权后的规范路径会继续传给工具执行，并在实际读取前再次检查最终目标。
- Fast 模式改为组合 Pi 的 payload hook，不再替换流函数，保留 SDK 的流身份、OAuth 摘要和扩展转换行为。
- 扩展对话在会话中止、关闭或删除时会被取消，Host 关闭时会清空剩余请求，并忽略迟到的响应。

## 扩展、工具与会话元数据

- 扩展包列表不再隐式安装依赖；必需的 Web 能力改为可重试的单次后台安装，不阻塞本地会话、导出和包列表。
- 修复访问模式切换或扩展重载后延迟工具、非活动工具和显式停用工具状态丢失的问题。
- 扩展更新现在区分版本已变化、未变化和无法验证，并可安全预览目标版本区间内的本地 changelog；预览限制为 256 KiB，拒绝目录穿越和符号链接逃逸。
- ACP 用量更新和会话快照会保留响应模型与来源信息；工具完成记录会保留持续时间和嵌套调用 ID。
- Device Code 登录不再自动打开浏览器，浏览器和剪贴板操作需要用户明确点击，同时保留原有的普通浏览器 OAuth 行为。

## 聊天渲染与工具进度

- Host 在规范化和分配事件序号前，以固定 50 ms 窗口合并同一工具的进度更新；文本、审批、完成和错误事件不会被延迟或丢弃。
- 每个工具行会复用解析后的输入、编辑差异和统计信息，完整输入仅在需要时格式化，减少流式输出期间的重复 JSON 和 diff 计算。
- 修复 RTK 输出中跨数据块拆分的 UTF-8 字符，并增加真实进程回归覆盖。

## Bun 1.4.2 与单 Runtime 架构

- 将 Bun 从 1.3.14 升级到 1.4.2。内置 Bun 现在同时运行 AgentHost 并承担扩展包管理，不再通过 `bun build --compile` 重复嵌入第二份 Bun Runtime。
- AgentHost 改为可迁移的 Bun JS bundle；只有共享 Bun 是可执行文件，Host bundle 作为普通签名资源分发。
- Runtime manifest 新增 `bun-bundle` 格式，同时继续兼容旧的 `compiled` Runtime；安装、完整性、架构、签名、回滚和健康检查均已适配。
- Photon WASM、主题和 HTML 导出资源从 Host bundle 旁加载，发布检查会拒绝构建机器绝对路径，并在隐藏构建依赖后执行真实图片处理 smoke test。

## Pi 1.5 and runtime security

- Upgrades Pi AI, Coding Agent, and TUI to 1.5.0 with real agent-loop contract coverage for OAuth summarization, MCP OAuth, argument validation, and macOS shell cancellation.
- Read-only access now uses Pi's path rules consistently for `@`, `~`, file URLs, and macOS filename variants. The authorized canonical path is passed to execution and the final read target is checked again.
- Fast mode composes with Pi's payload hook instead of replacing the stream function, preserving SDK stream identity, OAuth summarization, and extension transformations.
- Extension dialogs are cancelled when their session is aborted, closed, or deleted; shutdown drains remaining requests and late responses are ignored.

## Extensions, tools, and session metadata

- Listing extension packages no longer triggers installation. Required web capability setup is a retryable single-flight background task that does not block local sessions, exports, or package listing.
- Preserves deferred, inactive, and explicitly disabled extension tools across access-mode changes and extension reloads.
- Extension updates distinguish changed, unchanged, and unverifiable versions and can safely preview the installed version interval from a local changelog. Previews are limited to 256 KiB and reject traversal or symlink escapes.
- ACP usage updates and snapshots preserve response-model and provenance metadata. Tool completion records retain duration and nested-call identity.
- Device-code authentication requires explicit browser or clipboard actions while ordinary browser OAuth keeps its existing behavior.

## Chat rendering and tool progress

- Coalesces each tool's progress over a fixed 50 ms Host window before normalization and sequence assignment. Text, approval, completion, and error events are never delayed or dropped by the buffer.
- Reuses parsed tool input, edit diffs, and statistics per row, formatting full input only when needed to avoid repeated JSON and diff work during streaming.
- Fixes UTF-8 characters split across RTK process-output chunks with a real-process regression test.

## Bun 1.4.2 and the single-runtime architecture

- Upgrades Bun from 1.3.14 to 1.4.2. The bundled Bun now runs AgentHost and manages extension packages, eliminating the second Bun runtime previously embedded by `bun build --compile`.
- Distributes AgentHost as a relocatable Bun JavaScript bundle. Only the shared Bun binary is executable; the Host bundle is a regular signed resource.
- Adds the `bun-bundle` runtime manifest format while retaining compatibility with legacy `compiled` runtimes. Installation, integrity, architecture, signing, rollback, and health checks support both formats.
- Loads Photon WASM, theme, and HTML export resources beside the Host bundle. Release checks reject build-machine paths and run real image-processing smoke tests with build dependencies hidden.
