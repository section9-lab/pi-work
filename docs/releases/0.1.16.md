PiWork can now update itself inside the app.

- Check for updates automatically on launch and daily while running. Automatic checks can be changed in Settings → General.
- Click Install Update to download, verify, install, and restart PiWork. Progress, download cancellation, and retry are available in the app.
- Verify signed update feeds and installers before installation, with separate Apple Silicon and Intel feeds.
- Preserve macOS 13 support and existing conversations, settings, and agent runtimes.

Users of earlier releases need to install this version manually once. Future releases can be installed from inside PiWork.

PiWork 现已支持应用内升级：启动时及运行期间自动检查更新，点击「升级」即可自动下载、校验、安装并重启。支持进度显示、取消下载和失败重试，并验证更新 feed 与安装包的签名。

保留 macOS 13 支持、现有对话、设置和 Agent 运行时。旧版本用户需先手动安装本版本一次，之后即可使用应用内升级。
