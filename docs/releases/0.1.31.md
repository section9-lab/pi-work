# PiWork 0.1.31

## 提问导航可见性修复

- 修复 v0.1.30 正式 Session 界面中提问导航消失的问题：原来的布局只在聊天区域宽度达到 868pt 时显示导航，默认窗口、较宽侧边栏或打开变更面板后可能完全看不到。代码并未漏打包，而是被显示条件隐藏。
- 现在只要会话有用户消息，就保留右侧导航；正文为导航预留独立空间，不再依赖窗口两侧恰好有空白，也不会与消息内容重叠。
- 保留短点、悬浮展开、提示词预览和点击跳转交互。
- 新增针对真实 ChatView 的渲染回归检查，覆盖 472–1000pt 聊天区域及连续调整大小。相同检查可复现旧版本在 840pt 下隐藏导航的问题。

## Prompt navigation visibility fix

- Fixed prompt navigation disappearing in the actual Session interface in v0.1.30. The rail previously required a transcript viewport at least 868pt wide, hiding it in normal-sized windows, beside wide sidebars or when the changes panel was open. The implementation was packaged, but its visibility condition suppressed it.
- Conversations with user messages now always retain the rail. The transcript reserves a separate trailing gutter instead of relying on spare space around the centered content, preventing overlap with messages.
- Preserves short resting marks, hover expansion, prompt previews and click-to-jump navigation.
- Added a rendered regression test of the real ChatView across 472–1000pt viewports and repeated resizing. The same test reproduces the previous version's missing navigation at 840pt.
