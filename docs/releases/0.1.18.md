Review project code changes inside PiWork.

- Expand a project in the Work sidebar and open Code Changes to see its changed files.
- Select a file to review additions, deletions, and line numbers. The view includes staged, unstaged, and untracked files, plus renames, deletions, and binary-file notices.
- Filter the file list and refresh without leaving your conversation or losing its draft. Git operations are read-only and compare the current working tree with HEAD.
- Keep large diffs bounded, display truncation notices, and handle empty repositories, clean working trees, and errors.
- Include the latest analytics dashboard and history-migration documentation.
- Preserve the account-row update button, running-task protection, macOS 13 support, and signed Apple Silicon and Intel update feeds.

PiWork 现已支持在项目内查看代码变更。展开 Work 侧栏中的项目，点击「代码变更」，即可筛选变更文件，逐个查看增删内容和行号。

支持暂存区、工作区、未跟踪文件、重命名、删除和二进制文件提示。界面只读，比较基准为 HEAD；查看变更不会离开当前对话或丢失草稿。大文件差异会显示截断提示，并提供刷新、空状态和错误反馈。

本次也纳入最新的统计看板与历史数据迁移文档。保留头像旁更新按钮、运行任务保护、macOS 13 支持以及两个架构的签名更新 feed。
