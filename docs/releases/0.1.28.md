# PiWork 0.1.28

## 技能简介加载

- 修复技能商场部分卡片一直停在灰色占位、始终不显示简介的问题：技能站点只在详情页提供简介，有些技能页（已下架或没有填写简介）永远拿不到内容，现在会明确显示「这个技能没有提供简介」，不再是一个空占位条。
- 简介请求限制为同时四条，正在看的卡片先出内容，不再和屏幕外的卡片抢带宽。
- 单页超时从 30 秒收紧到 12 秒；遇到网络抖动会自动重试一次，解析不出简介的页面不会反复重试。
- 已经取到（或确认没有）的简介会随目录缓存写盘，下次打开和重新滚动都直接命中，不再重复请求。
- 加载中的状态改为两行骨架条，与「没有简介」的说明文字一眼可分。

## Skill descriptions

- Fixed cards that sat on a grey placeholder and never showed a description: the directory only publishes descriptions on the per-skill page, and skills whose page has none (delisted or undocumented) now say "No description published for this skill" instead of holding an empty bar forever.
- Description requests are capped at four at a time, so cards on screen fill in first instead of competing with everything below the fold.
- The per-page timeout drops from 30s to 12s, transport hiccups get one retry, and pages that parse without a summary are not retried again.
- Resolved descriptions — including the "nothing published" verdict — are written to the catalog cache, so reopening or scrolling back hits the cache instead of the network.
- The loading state is now a two-line skeleton, clearly different from the muted "no description" sentence.
