# PiWork 0.1.50

## 打开历史会话更快

- 打开会话时直接把已知的 session 文件路径传给 Agent Host，Host 会直接读取目标文件，不再为了解析一个 session ID 而扫描整个项目的会话目录。
- 在包含 30–39 个会话、总计 133–185 MB 的项目中，目录扫描原本需要 344–454 ms；现在这段扫描在路径有效时完全跳过。
- 只有路径缺失或文件已经不存在时，才回退到原来的目录扫描，因此删除、移动或旧版本产生的会话仍然可以正常打开。
- Host 恢复已选中的会话时也会复用记录中的真实路径。

## Faster historical sessions

- Opening a session now forwards its known file path to the Agent Host. The host opens the target file directly instead of scanning every session in the project just to resolve one session ID.
- In projects with 30–39 sessions totaling 133–185 MB, that catalog scan took 344–454 ms; it is now skipped when the path is valid.
- The catalog fallback remains for missing paths or files that no longer exist, so deleted, moved, or older sessions still open correctly.
- Host recovery for selected sessions also reuses the real path from the session record.
