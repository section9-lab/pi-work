# PiWork 0.1.47

## 流式 Markdown 性能

- 助手回复改为按顶层块渲染：已冻结的前缀被切成独立块，每块只解析一次，未变化的块由 SwiftUI 直接跳过，不再每次刷新都重排整份文档。
- 默认只保留最新 6 个块挂载，更早的块用实测高度占位，文档总高度与整篇渲染完全一致（各滚动位置偏差 0 pt）。
- 当读者滚离末尾，或开启 VoiceOver 时自动关闭窗口化，保证眼前看到的始终是真实视图。
- 回复结束时仍执行一次整文档精确解析，最终结果与之前完全相同。
- 实测每 tick 耗时（Release）：4.6 KB 71.6 ms → 10.0 ms，9.2 KB 83.2 ms → 12.4 ms。
- 环境变量 `PIWORK_MARKDOWN_BLOCK_MEMO` 可切换策略：0 整篇、1 记忆化、2 懒加载、3 窗口化（默认）。

## Streaming Markdown performance

- Assistant replies are now rendered per top-level block: the frozen prefix is split into independent blocks, each parsed once, and unchanged blocks are skipped by SwiftUI instead of re-laying out the whole document on every tick.
- Only the newest six blocks stay mounted by default; older blocks become measured-height placeholders, keeping document geometry identical to one whole-document view (0 pt drift at every scroll position).
- Windowing turns itself off while the reader is scrolled away from the tail or VoiceOver is running, so what is on screen is always real views.
- Completing a reply still performs one exact whole-document parse, so the final state is unchanged.
- Measured per-tick cost (Release): 4.6 KB 71.6 ms → 10.0 ms, 9.2 KB 83.2 ms → 12.4 ms.
- `PIWORK_MARKDOWN_BLOCK_MEMO` selects the strategy: 0 whole document, 1 memoized, 2 lazy, 3 windowed (default).
