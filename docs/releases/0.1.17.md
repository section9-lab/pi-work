Updates are now visible beside your account in the sidebar.

- Show Update when a new version is available, compact download progress while preparing it, and Restart when it is ready.
- Keep updates from interrupting Chat, Work, or scheduled tasks. While any task is active, clicking Update or Restart does nothing and its hover hint asks you to finish tasks and click again.
- If a task starts during a download, keep the prepared update ready for an explicit Restart click. Finishing a task never starts a queued upgrade or restart.
- Replace the top update banner with the account-row control, while retaining manual checks and automatic-check preferences in Settings.
- Route anonymous usage reporting to PiWork's dedicated analytics project.
- Preserve macOS 13 support, separate Apple Silicon and Intel installers, and signed update feeds.
