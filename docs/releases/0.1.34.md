# PiWork 0.1.34

## 会话分享与右上角操作

- 将“导出 HTML 报告”从侧栏右键菜单移到会话右上角，使用原生分享图标；点击后导出当前会话并在默认浏览器中打开。
- 分享与项目菜单组成 Safari 风格的双按钮胶囊，使用系统 SF Symbols，适配深色模式与 macOS 26 的原生玻璃材质；旧系统使用系统材质。
- 切换会话、任务执行或正在导出时禁用分享，避免导出错误会话或重复操作。

## 与终端 Pi 共用环境

- 设置、服务商凭据、会话、技能与扩展改为使用标准目录 `~/.pi/agent`，与默认配置的终端 Pi 共用。
- **升级提示：原目录 `~/Library/Application Support/pi-work/Agent` 中的数据不会自动迁移，也不会删除。** 如果此前仅在应用中配置服务商或保存会话，升级后需自行迁移所需数据；新界面展示的是共用目录中的配置与会话。
- 在应用或终端中修改共用配置、安装或移除扩展，会影响另一端；设置文案与文档已同步说明。
- 应用安装扩展时仍使用内置 Bun，但不再将应用专属的 Bun 路径写入共用设置，避免影响终端 Pi 的包管理器。

## Session sharing and upper-right actions

- Moves Export HTML Report from the sidebar context menu to a native share icon in the session's upper-right corner. Export still opens the current session's report in the default browser.
- Groups share and project-menu actions in a Safari-style two-button capsule, using SF Symbols, native macOS 26 glass, system-material fallback, and dark-mode support.
- Disables sharing while switching sessions, running tasks, or exporting to avoid targeting the wrong conversation or starting duplicate exports.

## Shared terminal Pi environment

- Settings, provider credentials, sessions, skills, and extensions now use the standard `~/.pi/agent` directory, shared with terminal Pi's default configuration.
- **Upgrade notice: data in the previous `~/Library/Application Support/pi-work/Agent` directory is neither migrated automatically nor deleted.** Users who configured providers or saved conversations only in the app must migrate any data they need; the updated interface uses the shared directory's configuration and sessions.
- Changes to shared settings and extension installation/removal affect both interfaces. Settings copy and documentation now explain this behavior.
- Desktop extension installation continues to use bundled Bun without persisting the app-specific Bun path into shared settings or changing terminal Pi's package-manager command.
