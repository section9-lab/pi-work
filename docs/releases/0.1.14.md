Computer use is now available on macOS 14 and later, with a dedicated settings page and a verified desktop observation/action workflow. The app continues to support macOS 13.

- Enable Computer Use in Settings, grant Accessibility and Screen Recording to the listed helper, and apply permissions by restarting only the control service. The built-in test checks an actual screenshot, writes test text, and independently reads it back.
- Desktop tools follow existing session permissions: read-only observation, approval requests, immediate disable/stop, and isolation of observation state between sessions.
- Add native MCP settings for local stdio and remote HTTP services, OAuth, per-tool permissions, and automatic connection checks.
- Add optional RTK command-output compression and local savings statistics in Settings.
- Add anonymous app launch and daily activity statistics, with an opt-out switch in Settings. Screenshots, conversations, files, commands, account identifiers, and session replay are excluded.
- Bundle pi-coding-agent 1.4.0 and runtime 1.1.0.

新增电脑使用功能：macOS 14 及以上可在「设置 → 电脑使用」开启，授权后仅重启控制服务即可生效。内置测试通过真实截图观察、输入测试文本及独立读回验证操作结果；同时接入现有会话审批与只读限制。主应用继续支持 macOS 13。

本版本还包含原生 MCP 服务管理、可选 RTK 输出压缩与统计，以及可在设置中关闭的匿名启动和日活统计。统计不包含截图、对话、文件、命令、账户标识或会话回放。
